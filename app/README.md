# 世界晨報｜Android App 雛形

這是以漸進式網頁 App（PWA）製作的 Android 手機版介面。安裝到主畫面後會以獨立 App 視窗開啟。新聞資料直接讀取你現有的「世界日報」網站，日期、繁體中文摘要、英文原標題、原文連結和圖片來源都沿用同一份 `news.json`。

## 目前功能

- 讀取世界日報新聞資料，依日期與發布時間排序
- 國際、台灣、政治、財經、科技、軍事、社會、環境、自然災害、科學、健康、文化、體育等分類
- 關鍵字搜尋、收藏、文章詳情、原始報導連結和圖片署名
- 手動更新、離線殼層快取，以及最後一次成功載入的新聞快取
- 晨報時間偏好設定與安裝型 PWA manifest

## Android 安裝

先將此資料夾部署至 HTTPS 網址，再用 Android Chrome 開啟。從瀏覽器選單選擇「安裝應用程式」或「加到主畫面」。

若已安裝 Node.js，可在本機預覽：

```sh
npx serve .
```

本機預覽只供操作介面；要安裝到手機需使用 HTTPS 網址。

## 尚待建置

- 每日固定時間推播：需要後端排程與推播服務，目前設定頁只保存提醒時間，不會在 App 關閉時主動通知。
- 新聞來源目前取自 `https://lalahie.github.io/world-brief/news.json`；若日後更改網站網址，需同步更新 `index.html` 中的 `FEED_URL`。
