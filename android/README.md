# 世界晨報 Android 1.2

原生 Kotlin / Jetpack Compose 新聞閱讀器。使用 Android Studio 開啟 `android/` 目錄，Gradle JDK 選擇 17 或 21，安裝 Android SDK 35，再選擇裝置及 `app` 執行配置。

完整功能及操作方式見 [START-HERE.md](START-HERE.md)，Firebase 推播設定見 [FCM-SETUP.md](FCM-SETUP.md)。

桌面長按空白處，新增世界晨報小工具，拖曳調整尺寸；在 App 設定中即可選擇顯示今日、台灣或國際新聞。背景更新受 Android 排程限制，也可手動重整。
